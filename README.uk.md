# Site Visual Editor (SVE)

[English](README.md) | **Українська**

**Демо:** <https://garevna.github.io/sve-studio/> - редактор; сайт, який він створює, - <https://garevna.github.io/sve-studio/site/>. Усе, що ви змінюєте, лишається у вашому браузері.

Візуальний редактор багатомовних сайтів: сторінки складаються з готових блоків, редагуються на місці й публікуються без жодного коду.

- **Блоки - по одному.** Кожен блок виглядає точнісінько як на сайті; клік відкриває його для редагування. Приховати, перемістити чи видалити - з його меню.
- **Галерея блоків.** Нові блоки обираються з живих прев'ю у кольорах і шрифтах самого сайту й стають саме туди, де натиснули «+».
- **Структура сторінки.** Уся сторінка списком: перетягнути, щоб змінити порядок, приховати й показати, перейти до блоку.
- **Кілька мов.** Кожен текст, назва сторінки й пункт меню - кожною мовою сайту.
- **Одна назва для сторінки.** Меню показує назву самої сторінки; перейменуйте сторінку - і меню зміниться саме.
- **Вигляд сайту.** Палітра, UI Kit, шрифти, макети шапки й футера, власні стилі сайту.
- **Вигляд редактора.** Кілька кольорових схем самого редактора, щоб він ніколи не зливався з сайтом, який редагують.
- **Працює на телефоні.** Інструменти переїжджають у нижню панель, панелі виїжджають знизу.

Демо зберігає все, що ви робите, у вашому власному браузері: нічого з того, що ви створюєте, не зберігається на сервері.

## Запуск локально

Node 24 (див. `.node-version`; з [fnm](https://github.com/Schniz/fnm): `fnm use`) і pnpm.

```sh
pnpm install
pnpm dev
```

Редактор відкривається на <http://localhost:3006>, сайт, який він редагує, - на <http://localhost:3006/site/>.
